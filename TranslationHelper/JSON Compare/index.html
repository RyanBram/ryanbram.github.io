ℹ️ About RPG Maker Translation Helper

RPG Maker Translation Helper - i18n Mode is a browser-based tool for creating compact translation mapping files for RPG Maker MV/MZ games.

🔌 RPG Maker Plugin Required

To enable runtime language switching in your game, you need to install the rpg_locale.js plugin in your RPG Maker project.

🔄 Two Operating Modes

  • SERVER MODE (http://): Full features including automatic translation with Bergamot
    • Run: python -m http.server or use any web server
    • Access: http://localhost:8000
    • All features available
  • LOCAL MODE (file://): Basic features without automatic translation
    • Double-click index.html to open
    • Upload, extract, copy, paste, rebuild JSON ✅
    • Automatic translation disabled ❌
    • Use external tools (Google Translate, DeepL, ChatGPT)

✨ Key Features

  • Source Language Selection: Choose the language of your extracted text (Arabic, Chinese, English, German, Spanish, French, Indonesian, Japanese, Korean, Portuguese, Russian)
  • Multi-language Support: Translate multiple languages simultaneously
  • Compact Format: Generates i18n mapping files (not full JSON duplication)
  • Merge-friendly: Preserves existing translations when adding new languages
  • Validation: Strict line-count checking prevents corrupted translations
  • Offline Translation: Built-in Bergamot translator (server mode only)
  • Flexible Usage: Works with or without a web server

📋 How to Use

  1. Upload Source JSON: Drag & drop your RPG Maker JSON file (Actors.json, Items.json, Map001.json, etc.)
  2. Select Source Language: Choose the language of the extracted text from the "Source" dropdown (Arabic, Chinese, English, German, Spanish, French, Indonesian, Japanese, Korean, Portuguese, Russian)
  3. Select Target Languages: Click "Select Languages..." and choose target languages
  4. Option A - Upload Target JSON (NEW!): Upload a complete translated JSON file (e.g., Actors_en.json) to automatically extract and compare translations
  5. Option B - Manual Translation: Click "Copy" to get the original text, use "Translate All" for automatic translation, or paste to your translation tool (Google Translate, DeepL, ChatGPT, etc.)
  6. Option C - Existing i18n: Upload existing *_i18n.json to merge/update translations
  7. Paste Back (if manual): Paste translated text into the corresponding language column
  8. Build i18n: Click "Build i18n" to generate the mapping file
  9. Download: Save the *_i18n.json file to ./data/locales/ folder

💡 Tips

  • NEW: Upload a complete target language JSON to auto-extract translations!
  • Upload existing i18n file to preserve previous translations
  • Set the correct source language before translating
  • Use "Translate All" for quick automatic translation with Bergamot
  • Use AI translation tools for faster batch translation
  • Target JSON comparison works best with same file structure (e.g., both Actors.json)
  • Each line in source = one line in translation (strict matching)
  • You can translate multiple languages at once to save time
